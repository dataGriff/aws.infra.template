# Tutorial — build the platform yourself

Reconstructs the platform from an empty repo as an **epic → ticket backlog**
(_title · problem · acceptance criteria · effort_, one reviewable PR per ticket). See
[backlog.md](backlog.md). Epics:

1. Foundations & DX
2. Bootstrap: state + OIDC trust
3. Network & encryption
4. Identity
5. Edge: WAF, DNS, static IPs
6. Alerting, budget, account settings
7. The published interface
8. CI/CD
9. Docs & the register-service skill
